# Bug Report: Login blocked for locked_out_user
**Bug ID**: BUG-001 | **Severity**: High | **Test Case ID**: TC-011
**Target URL**: https://www.saucedemo.com

### Description
User 'TC-011' failed to authenticate and access the inventory dashboard. Instead of successful authentication and redirection to the inventory page, the login was rejected with an error banner indicating that the user has been locked out.

### Steps to Reproduce
1. Navigate to https://www.saucedemo.com
2. Enter username 'locked_out_user'
3. Enter password 'secret_sauce'
4. Click 'Login' button

### Expected vs Actual
- **Expected**: User is successfully authenticated and redirected to Inventory page (https://www.saucedemo.com/inventory.html).
- **Actual**: Login failed unexpectedly with error: 'Epic sadface: Sorry, this user has been locked out.'. User remained on login page instead of redirecting to /inventory.html.
